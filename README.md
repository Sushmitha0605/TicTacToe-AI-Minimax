#Tic Tac Toe with AI (Java)
Overview
  *This is a console-based Tic Tac Toe game I made in Java. You can play it in:
  *Two Player Mode: Player X vs Player O
  *Single Player Mode: Player vs AI with three difficulty levels
  *The AI is really smart in Hard mode—it uses the Minimax algorithm, so it’s basically unbeatable. 

#Features
  *Play with a friend or challenge the AI
  *Three AI difficulty levels:
  *Easy → Makes random moves
  *Medium → Tries to win or block you
  *Hard → Uses Minimax (unbeatable)
  *Prevents invalid moves
  *Shows the game board and checks for wins or draws after each move

#What I Learned
  *How to implement AI with the Minimax algorithm
  *Managing game states and input validation in Java
  *Making a simple console game that’s interactive and fun
